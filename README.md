## hwat, hwy & hwere

base tooling & scripts to build & run the shelly repo focusing on a reproducible linux installation.
this will clear & overwrite config files for rioterm, nvim & nushell

# Pre-req (wip)
- git   `sudo apt install git`
- nu    `sudo apt install nushell`
- cargo (incl. rustup & rustc)
- node (easiest install through app center on ubuntu - "node.js runtime")
- rioterm (optional - deb packages in gh releases)

----

# Installation

run:

then with prerequisets install run the 'init.nu' script'

`nu ./init.nu`
